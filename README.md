# 🚀 ConversAI — v2

**ConversAI v2** is a full-stack conversational AI web application that allows users to interact with an intelligent chatbot using natural language. This project demonstrates the integration of AI-powered responses with a modern web-based chat interface.

---

## 🧠 Overview

ConversAI v2 is an improved and more structured version of the original ConversAI project. It focuses on clean separation between frontend and backend, scalable design, and real-time conversational interaction. The project highlights practical implementation of conversational AI concepts in a web environment.

## ⚙️ Installation & Setup

### Prerequisites

* Node.js (v14 or higher)
* npm

---

### Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/taslimansari/conversAIv2.git
   cd conversAIv2
   ```

2. **Install backend dependencies**

   ```bash
   cd backend
   npm install
   ```

3. **Install frontend dependencies**

   ```bash
   cd ../client
   npm install
   ```

4. **Environment Variables**

   Create a `.env` file in the backend directory and add:

   ```
   OPENAI_API_KEY=your_api_key_here
   ```

5. **Start the backend server**

   ```bash
   cd ../backend
   npm start
   ```

6. **Start the frontend**

   ```bash
   cd ../client
   npm start
   ```

7. **Open the application**

   ```
   http://localhost:3000
   ```

## 🧪 Usage

Type a message in the chat input box and submit it. The backend processes the message using an AI language model and returns a contextual response in real time.
